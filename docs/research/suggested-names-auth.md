# Suggested Project Names — Auth (iOS + Vapor Authentication SPM)

> Note: This is an SPM library, not an App Store product. "Availability" below refers to
> Swift Package Index / GitHub namespace conflicts, not App Store listings.

**Confirmed name: Auth**

The following alternatives were proposed and reviewed before the decision was made to keep the original working name.

| Name | Swift Package Index / GitHub | Notes |
|------|------------------------------|-------|
| **Auth** ✅ chosen | ✅ Available | Simple, direct, unambiguous. No conflicts on Swift Package Index for this exact name under a personal namespace. |
| AuthKit | ⚠️ Similar exists | Generic but clean; several community repos use it informally. |
| VaporShield | ✅ Available | Evokes security + Vapor; undersells the iOS client side. |
| SwiftAuth | ⚠️ Similar exists | Conflicts with some older abandoned repos. |
| AuthBridge | ✅ Available | Directly communicates iOS ↔ Vapor bridging. |
| LayeredAuth | ✅ Available | Reflects the three-target architecture. |
